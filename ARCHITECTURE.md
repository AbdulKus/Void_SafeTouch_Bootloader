# Архитектура Void Bootloader

## Разметка Flash

| Раздел | Диапазон адресов | Размер | Политика обновления |
|---|---:|---:|---|
| Void Recovery, stage 0 | `0x00100000..0x00100FFF` | 4 КиБ | только JTAG |
| Void Bootloader, stage 1 | `0x00101000..0x00102FFF` | 8 КиБ | обновление по USB |
| Приложение | `0x00103000..0x0010FFFF` | 52 КиБ | обновление по USB |

Stage 0 всегда запускается первым. Перед передачей управления он проверяет
заголовок, границы и CRC образа stage 1. Если stage 1 отсутствует или повреждён,
либо при подаче питания удерживаются обе кнопки, stage 0 остаётся в режиме USB
recovery.

Stage 1 аналогично проверяет приложение. Поэтому оборванное обновление
приложения возвращает устройство в Void Bootloader, а оборванное обновление
stage 1 — в Void Recovery.

Ни один USB-этап не принимает запись за пределами своего целевого раздела.
Security bit AT91 не устанавливается. Аппаратную блокировку 4-КиБ области stage 0
следует включать только после проверки холодного запуска recovery на конкретной
плате.

## Формат и атомарная фиксация образа

Каждый обновляемый раздел начинается с отдельной 128-байтной страницы Flash с
заголовком `VRB1` для загрузчика или `VAP1` для приложения. Исполняемое тело
начинается со следующей страницы.

Во время обновления загрузчик выполняет операции в следующем порядке:

1. делает старую страницу заголовка недействительной;
2. последовательно записывает страницы тела образа;
3. проверяет длину и CRC32 всего тела;
4. последней операцией записывает валидный заголовок;
5. повторно проверяет готовый образ непосредственно во Flash.

Поэтому потеря питания до четвёртого шага не может привести к запуску частично
записанного кода.

## Переходы между этапами

Stage 0 принимает запись только в stage 1. Stage 1 принимает запись только в
раздел приложения. Команда `0x21` передаёт управление из stage 1 в stage 0 с
сохранением настроенного HID-соединения. Это необходимо потому, что аппаратную
подтяжку D+ данной платы нельзя надёжно отключить программно. После успешного
обновления stage 1 управление возвращается тем же способом.

Удержание обеих кнопок при подаче питания принудительно оставляет устройство в
stage 0. Удержание зелёной кнопки оставляет его в stage 1 вместо запуска
приложения.

Stage 1 разворачивает LCD на 180°, устанавливает контраст `0x04` и выводит:

```text
    VOID
bootloader
    v1.1
```

USB product string равен `Void Bootloader`. Windows показывает стандартное имя
`USB Input Device`, поскольку интерфейс использует бездрайверный HID-класс.

