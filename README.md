# Void SafeTouch Bootloader

Открытая прошивка, USB-загрузчик и аппаратная документация для снятого с
производства терминала чтения смарт-карт **SafeTech SafeTouch**.

Устройство построено на **Atmel AT91SAM7S64**: ядро ARM7TDMI, корпус LQFP-64,
64 КиБ Flash и 16 КиБ SRAM. Проект заменяет штатную прошивку следующими
компонентами:

- неизменяемый аварийный загрузчик `Void Recovery` размером 4 КиБ;
- обновляемый по USB основной загрузчик `Void Bootloader` размером 8 КиБ;
- раздел приложения размером 52 КиБ;
- HID-прошивальщик, не требующий отдельного драйвера в Windows и Linux;
- поддержка LCD и готовый пример меню с кнопками и светодиодами.

> [!WARNING]
> Первичная установка уничтожает штатную прошивку SafeTouch. Считать её не
> удалось из-за установленного security bit. Не устанавливайте security bit
> повторно. Никогда не подавайте 3,3 В на площадку `ERASE`, если полное стирание
> Flash не является осознанной целью.

## Проверенная версия устройства

Проект испытан на SafeTouch с маркировкой:

```text
HW 01.01.06c
FW 1.6.1 Strong
build 26.07.2013
```

На контроллере LCD нет читаемой маркировки. По электрическому интерфейсу и
системе команд это **монохромный COG LCD 132×64, совместимый с
ST7565/ST7567**. Это идентификация по поведению, а не подтверждённый номер
микросхемы.

Полные таблицы разъёмов, LCD и GPIO находятся в
[docs/HARDWARE.md](docs/HARDWARE.md).

## Разделы Flash и защита от сбоя питания

| Раздел | Адрес | Размер | Способ обновления |
|---|---:|---:|---|
| Void Recovery, stage 0 | `0x00100000` | 4 КиБ | только JTAG |
| Void Bootloader, stage 1 | `0x00101000` | 8 КиБ | USB recovery |
| Приложение | `0x00103000` | 52 КиБ | USB bootloader |

При обновлении загрузчик сначала делает заголовок целевого раздела
недействительным, затем записывает 128-байтные страницы Flash, проверяет CRC32
и только после этого фиксирует новый заголовок. После оборванного обновления
приложения устройство возвращается в stage 1, а после оборванного обновления
stage 1 — в stage 0. Stage 0 никогда не принимает команды записи в собственный
4-КиБ раздел.

Формат образа и последовательность восстановления описаны в
[ARCHITECTURE.md](ARCHITECTURE.md).

## Сборка

Необходимы:

- Arm GNU Toolchain: `arm-none-eabi-gcc`, `objcopy`, `size`;
- Python 3;
- PowerShell в Windows или Bash в Linux.

Windows:

```powershell
.\build.ps1
```

Linux:

```bash
./build.sh
```

Сборка создаёт `void_recovery.bin`, `void_bootloader.vbi` и
`examples/menu/menu.vbi`. GitHub Actions автоматически собирает те же файлы
при каждом push и pull request.

## Первичная установка через JTAG

Питайте SafeTouch через его штатный USB-разъём. `VTref` программатора подключайте
к площадке 11 только как вход опорного напряжения; не пытайтесь питать плату от
программатора.

После подключения сигналов по таблице из [аппаратной документации](docs/HARDWARE.md)
запишите два файла командами OpenOCD:

```text
program void_recovery.bin verify 0x00100000
program void_bootloader.vbi verify 0x00101000
```

Файл [tools/openocd/safetouch.cfg](tools/openocd/safetouch.cfg) содержит
описание TAP и целевого AT91SAM7S64. Конфигурация адаптера оставлена отдельно,
поскольку CMSIS-DAP, FT232H, ESP USB-JTAG и другие программаторы используют
разные интерфейсные файлы.

После первой записи один раз физически переподключите USB SafeTouch. Windows
определит `VID_1209:PID_B007` как `USB Input Device`. В USB-дескрипторе записано
имя `Void Bootloader`, но Диспетчер устройств показывает стандартное имя класса,
поскольку загрузчик специально использует HID без отдельного драйвера.

Идентификатор `1209:B007` экспериментальный. Для коммерческого распространения
необходимо получить отдельный PID.

## USB-прошивальщик

Создайте виртуальное окружение и установите единственную зависимость:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install hidapi
.\.venv\Scripts\python.exe .\voidtool.py info
```

В Linux путь к Python будет `.venv/bin/python`. Для доступа к HID без root может
потребоваться правило udev.

Обновление самого загрузчика:

```powershell
.\.venv\Scripts\python.exe .\voidtool.py upload .\void_bootloader.vbi --boot
```

Запись и запуск примера меню:

```powershell
.\.venv\Scripts\python.exe .\voidtool.py upload .\examples\menu\menu.vbi --boot
```

Если приложение уже установлено, удерживайте **зелёную кнопку YES** во время
подачи USB-питания, чтобы остаться в stage 1. Удерживайте **обе кнопки** при
подаче питания для принудительного входа в stage 0.

## Пример меню

Пример выводит прокручиваемое меню:

- красная кнопка NO перемещает курсор;
- зелёная кнопка YES выбирает пункт;
- пункты `LED OFF`, `LED GREEN`, `LED RED` и `LED BOTH` задают мигающие светодиоды;
- `CONTRAST` меняет электронный контраст LCD от `00` до `3F`;
- `BACKLIGHT` включает и выключает подсветку через ключ на pin 10 / PA18;
- `SMART CARD` читает ATR контактной ISO 7816 карты и показывает полученный из
  ATR восьмизначный идентификатор либо состояние `CARD ABSENT` / `NO RESPONSE`.

В экране карты красная кнопка NO возвращает в меню, зелёная YES повторяет чтение.

Экран развёрнут на 180°, электронный контраст установлен в `0x04` — эти
параметры подобраны на проверенном экземпляре. Исходники находятся в
[examples/menu](examples/menu).

## Ограничения

- проверена только одна ревизия платы SafeTouch;
- точная модель контроллера LCD не установлена; ключ подсветки подтверждён на
  pin 10 / PA18;
- из-за ограничения в 4 КиБ stage 0 не содержит полноценного графического UI;
- CRC32 обнаруживает повреждение образа, но не является криптографической подписью;
- лицензия проекта пока не выбрана.
